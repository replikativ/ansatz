# Private complete Expr metavariable instantiation

This private active-explicit research job runs both pinned native algorithm
passes and returns the two-field `[currentContext, finalExpr]` result. It uses
one context cell and one work budget, existing nineteen-role source/ABI policy,
authentic ordinary guest constructors/accessors/getters/setter, and the existing
Level, beta, lift and scoped-cache workers. Native530 remains unregistered. No
public full-instantiation capability or original frontend completion follows.

The fixed reflective research entry accepts owned context and Expr occurrences.
It preflights the configured Level policy and all nineteen current ordinary
helpers before claiming inputs; exact known input alias credits are checked.
Headers carry descriptive source identity, not self-authenticating code hashes.
The loader and future public adapter must separately authenticate actual source
and code/state closure. Existing private direct-report and Stage4 protocols keep
their own entry/result shapes.

The first pass retains its saved assignments, normalized Name owners, Expr
cache and Level members after producing e1. The original input occurrence
retires at the source assignment semicolon. With no updateable delayed MVars,
e2 acquires an independent copy of e1. Otherwise the second pass borrows e1 and
uses its own transform lifecycle, independent of its foundation resolver phase.
Its members drain before pair allocation. The pair moves the current cell and
e2 owners atomically, then remains owned through e1 and first-pass member drains.
Failure preserves the actual latest context, source stage and unfinished owners;
there is no rollback, general failed-session unwind or successful-failure cleanup.

Pass two shortcuts exactly when there are no Expr MVars and either no FVars or
an empty semantic substitution map. Shared visits use identity plus binder depth
in the existing generation/scope-aware cache. Entry sharing is sampled once.
Cache hits propagate scope without resetting the parent watermark; misses reset
and later restore it. FVar substitution and bare outer MVar results skip cache
insertion. Domains precede binder bodies; let type/value precede body. Computed
child locals retire in source order before composite cache insertion. Application
prefixes traverse arguments first and bypass NORMAL cache only along intermediate
function Apps. This differs from pass one and arbitrary callback Expr replacement.

Outer assignment normalization uses a separate semantic Name set, inserts before
visiting even an MVar-free assignment, and saves an old assignment occurrence
before a changed setter steals the context cell. Inner assignment results move
into their private optional without writeback or a fabricated guest Some. The
outer/inner branch is sampled before recursive visits. Resolvability caches
remain intact after successful writeback, matching pinned source behavior.

Delayed applications keep their Option, obtain fvars and pending Name through
separate owned record temporaries, then check arity. Resolution visits arguments
outermost first into an owning reverse buffer. Existing substitution frames alias
those exact credits without owning the buffer, restore duplicate mappings in
literal forward order, and preserve saved entries until beta returns. Beta gets
an owned copy of the computed function and a borrowed prefix of the argument
buffer. Pending Option, saved substitutions and arguments retire at their source
boundaries. A nonresolvable pending value is normalized for outer writeback before
structural fallback. Unsupported inner nonresolvability rejects explicitly.

Current-action-only selectors route helpers and constructors to the active direct
or delayed session. A sealed first pass cannot supply helpers during pass two.
Nested beta/lift actions supply their own packet while sharing the same budget.
Helper frame/Code publication marks exact argument-array transfer once; replies
stay owned in receiver storage before shape checks. Setter-null cells, retiring
credits, transformed children, scoped operations, restored frames, pending work,
partial pair and both sessions fork through the same iterative memo. Immutable
scope generations remain guest-reference-free and shareable.

Resource limits retain the existing one-million aggregate work budget, bounded
frames, cache entries, semantic Name/saved owners, generations, argument buffers
and binder depth. Name comparisons and all nested maintenance charge that budget;
interruption remains terminal. Valid cached flags and source-shaped acyclic Expr
storage are required. Contradictory atomic flags reject; legal semantic assignment
reentry is controlled by normalized Names and the bounded visitor rather than a
blanket raw-Expr active prohibition. No native heartbeat, allocation/RC trace,
unsafe cycle termination or arbitrary native panic behavior is claimed. JVM
unordered member collections drain deterministically, not as a claim of unsafe
native container-destructor ordering.
