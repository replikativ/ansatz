# Configured original Expr metavariable native

The active explicit runtime recognizes original `Lean.instantiateExprMVarsImp`
(`lean_instantiate_expr_mvars`, intrinsic 530). Its ABI is two owned OBJ arguments
and an owned constructor0 pair `[currentContext, finalExpr]`. The authentic owned
`_boxed` wrapper is supported unchanged. Raw root, FAP, PAP/AP, imported original
owned closures and an authorized boxed-wrapper HostGuest call use the same
production two-pass algorithm as the [private research job](JAVA_EXPR_FULL_RESEARCH.md).
No borrowed-native first-class fence is added.

Construct the existing immutable nineteen-role policy with
`ExprInstantiationPolicy.originalHelpers(actualLevelPolicy, exprHeaders[5], constructorHeaders[9])`.
This exposes the same exact validator used by the private research entry.
`configureExprInstantiation(policy)` is once-only at an open idle active-explicit
boundary. Its Level policy must be the actual configured object; an independently
created policy with the same tuple is not sufficient. Configuration preflights
all nineteen current ordinary Functions without forcing bodies. Fork inherits
both immutable policies with their identity relationship intact.

Every native entry, including no-MVar identity work, checks exact native typed
Name, original SHA and source identity, then every current helper/constructor
Function. Host, intrinsic or guest-export substitution of a helper rejects.
The loader authenticates actual source bytes and metadata; constructor hashes
alone are descriptive. This API grants no source lease, initialized-state proof,
kernel certificate or executable compiler-output admission.

The registry can recognize the raw ABI without an executable policy. Default,
inactive, recursive, wrong-source and unconfigured entry reject. Saturated AP
validates the native operands and known aliased input occurrences before capture
INC or closure retirement; raw root validates before publishing the invocation.
Ordinary callers may already have entered before an invalid FAP/AP reaches this
boundary. Failure therefore does not promise to roll back their instruction
counts or earlier effects. Existing owner/branch/carrier checks are not a
universal proof that arbitrary host Node references belong to this engine.

Native actions reuse the reviewed preparer and ownership records without a
private research counter reset. Incoming arguments alias their exact context and
Expr credits. The context cell, budget, both passes, helper packets, scopes,
caches, pending results and pair follow the reviewed source lifetime and same-memo
fork rules. Argument aliases clear only after final handoff. Root completion and
HostGuest helper completion remain distinct; suspended helpers restore the exact
parked outer request. Normal terminal-failure records retain the actual unfinished
owners; no general failed-session cleanup is claimed.
