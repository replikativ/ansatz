# Fixed typed bridge execution probe

Load probe.clj once after java-ir-baseline, then models.clj. This isolated
namespace has a private opaque Session registry; do not reload it while live.
It does not modify any existing opaque registry. If these exact namespaces were
already loaded from the original ignored worker files, reuse their definitions;
do not reload a `deftype` or registry merely because its source path moved.

The importer accepts only the exact four frozen native/source-phase captures in
the worker's gate2 directory. It selects the genuinely checked Nat and String
entries, excludes IO, authenticates native DefEq/type metadata and actual
raw/boxed IR against the source-phase rows, then reserves every selected static
Header before any body. Only builtin-supported extern ABIs and ordinary pure
closed values are admitted. Initializer/action/redirect dependencies and dynamic
application reject. This is bridge execution, not module startup or a Project.

Root REPL definitions/evaluation (replace paths with the actual worker locations):

```clojure
(load-file ".../native-project/typed-bridge/probe.clj")
(load-file ".../native-project/typed-bridge/models.clj")
(native-typed-bridge-models-v1/check!)
(def typed-bridge-probe-v1
  (native-typed-bridge-probe-v1/open! compact-name-basis-v1 ".../target/java-native-entry-evidence-v1/gate2"))
(doseq [n [(long 0) (long 42) Long/MAX_VALUE (.shiftLeft java.math.BigInteger/ONE 80)]]
  (assert (= n (native-typed-bridge-probe-v1/invoke! typed-bridge-probe-v1
                 (native-typed-bridge-probe-v1/entry-name "NativeEntryCases" "aliasIdentity") n)))
  (assert (= (inc' n) (native-typed-bridge-probe-v1/invoke! typed-bridge-probe-v1
                        (native-typed-bridge-probe-v1/entry-name "NativeEntryCases" "natStep") n)))
  (assert (= n (native-typed-bridge-probe-v1/invoke! typed-bridge-probe-v1
                 (native-typed-bridge-probe-v1/entry-name "NativeEntryImported" "viaImport") n))))
(doseq [s ["" "ascii" "a\u0000b" "λ😀"]]
  (assert (= (if (empty? s) "empty" "full")
             (native-typed-bridge-probe-v1/invoke! typed-bridge-probe-v1
               (native-typed-bridge-probe-v1/entry-name "NativeEntryCases" "stringCase") s))))
(native-typed-bridge-probe-v1/close! typed-bridge-probe-v1)
```

One actual explicit engine is reused; each call has 20,000 instructions and a
five-second cooperative deadline, advanced in quanta of 128. Arguments/results
admit only exact immutable Long/BigInteger (bounded 4096 bits) or valid UTF-16
String (bounded 65536 chars), and actual owned results are released before the
engine returns idle. Failure preserves its Session/result slot and permits no
retry or close/unwind claim. Healthy idle close is synchronous, not TaskRuntime
disposal. A String identity was not exported, so this gate claims only the actual
String branch with Unicode/NUL inputs.

The parent ran these exact definitions in its retained 512 MiB JVM: five model
families/38 assertions passed, as did twelve Nat calls and four String branch
calls on one reused engine. Long/MAX_VALUE plus one returned exact BigInteger;
the healthy idle engine closed normally. The portable acceptance.edn is the
actual parent record; validation.json pins it and the tested source bytes.
The worker launched no additional JVM or native process for this consumer.

## Captures and recreation

The four full-stream pins in probe.clj authenticate positive.stdout,
imported.stdout and the two corresponding source-phase exports. These are
complete native gate captures, not caller-provided type descriptors. They remain
outside Git (the individual evidence files are roughly 180 KiB); their digests
and producer/fixture pins are tracked. No default capture is downloaded or
silently regenerated by open!.

To recreate a gate directory under the documented native resource supervisor:

1. Build the separate NativeEntryEvidence helper using the pinned toolchain and
   scripts/build-entry-evidence.sh. Keep the legacy Export.lean/exporter intact.
2. Compile NativeEntryCases then NativeEntryImported from the tracked fixture
   directory to a private .olean directory. Set LEAN_PATH to that directory and
   the configured official toolchain library. Capture the actual original
   exporter `--source FILE --olean OUTPUT --local MODULE` streams as
   source-export-NativeEntryCases.stdout and source-export-NativeEntryImported.stdout.
3. Capture the helper `--entries requests.json` and `--entries imported-requests.json`
   outputs as positive.stdout and imported.stdout. Requests are the tracked
   native-entry-evidence fixtures; no entry is executed in this step.
4. Compare every full-stream SHA with the constants in probe.clj before opening.
   A compiler/exporter/source/output change requires a newly reviewed native
   receipt and consumer profile; a failing pin is not an invitation to replace it.

Fresh package loading can run the models without loading fixture data. Actual
execution requires the authenticated captures and the compatible runtime basis.
The ordinary native-project loader deliberately does not auto-load this separate
experimental registry or offer its Session as a public Project.
