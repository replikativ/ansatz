# T02: grind, port design and conformance suite (Plan Phase 2A, stage 1)

REPL port: 7912

## Context
`src/ansatz/tactic/grind.clj` is a heuristic cascade: Bool case-split fast path → rfl →
assumption → IH apply → subst → … → E-graph close late. It is not Lean's grind. Lean's grind
(`/home/christian-weilbach/Development/lean4/src/Lean/Meta/Tactic/Grind/`, entry
`Elab/Tactic/Grind`) is refutation-based:
- preprocess the goal and hypotheses,
- internalize the terms into an E-graph with congruence closure,
- run propagators (Bool/Prop connectives, constructors/injectivity, …),
- E-match theorem instances with generation bounds,
- run theory solvers,
- case-split with `splits`/`gen` budgets.

ansatz already has an E-graph (`grind/egraph.clj`), E-matching (`grind/ematch.clj`), proof
assembly (`grind/proof.clj`) and a solver hook (`grind/solver.clj`). Decision (by Christian): port
Lean's grind to Clojure faithfully, around these pieces where they fit.
