## Context

not tabled (there is a separate "tabled" section). It groups candidates by specificity before
priority, truncates them to `*max-candidates*` (32), and falls back to name guessing
(`ansatz.core/resolve-basic-instance`, the substring index in `build-instance-index`). Broad
catches (~15) turn bugs into "no instance" or a different instance. Today `decide` failed because
a scoped instance in the registry won.

resolution with generator/consumer nodes, `getInstances` through the DiscrTree, priority order,
