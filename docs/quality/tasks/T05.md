# T05: conformance suites, nat/int, option/prod and inductive predicates (Plan: Yardstick)

REPL port: 7915

## Goal
Same as T04 (read `docs/quality/tasks/T04.md` for the method, the template and the rules), for
three other domains:

1. **nat/int**, ~20 lemmas: arithmetic over user recursive functions (a fold/sum/length/
   max-of-list, a power/factorial). Proofs by `induction … <;> simp [...] <;> omega`, `simp_arith`,
   `Nat.le` reasoning, `Int` versions of a few, `Nat.sub` truncation cases, and `decide` on small
   closed facts.
2. **option/prod**, ~15 lemmas: user functions returning `Option`/`Prod` (find, lookup, unzip,
   partition). Proofs using `cases h : f x`, `match`, `simp [Option.map]`-style, `obtain ⟨a, b⟩ := p`,
   and `rcases`.
3. **prop-inductive**, ~15 lemmas: user inductive predicates (`Sorted`, `Mem`, `All`, a
   reflexive-transitive closure) and the lemmas Lean proves by `induction h`, `cases h`,
   `constructor`, `exact`, and `simp` with the predicate's constructors.

Files: `test/lean/{nat_int,option_prod,prop_inductive}_conformance.lean` and
`test/ansatz/{nat_int,option_prod,prop_inductive}_conformance_test.clj`.

## Scope fence and acceptance
As in T04: new files only, no `src/` changes, known gaps with cause diagnoses, green tests, scores
and a gap table grouped by cause in the result.
