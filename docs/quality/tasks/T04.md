# T04: conformance suites, records and bool/decide (Plan: Yardstick)

REPL port: 7914

## Goal
Measure how well ansatz runs everyday Lean proof scripts, in two new suites. Use
`test/lean/list_conformance.lean` + `test/ansatz/list_conformance_test.clj` as the template, and
the shared runner `test/ansatz/conformance_support.clj`.

1. **records**: lists of structures, field projections, association-list state.
   - Write ~25 lemmas in the shape of a verified reference model (see
     `test/lean/memory_model_probe.lean`): structures with 2–4 Nat/Bool/List fields; functions
     over `List Rec` (lookup by key, update by key, insert/remove, filter by field, map a field,
     counts/sums of a field).
   - Invariants as Bool functions (all keys distinct, every row's owner present, sorted by key)
     and their preservation under the operations.
   - Include implications, hypotheses as binders before `induction`, `cases h : e`, `simp_all`,
     `simp … at h`, `decide` on closed instances, `omega` on field arithmetic, and `obtain`/
     `rcases`/`match` on structures where Lean idiom uses them. Use each theorem's most natural
     Lean script.
2. **bool/decide**: Bool algebra and the comparison encoding.
   - Write ~25 lemmas: `&&`/`||`/`!` laws over user Bool functions, `if` on comparisons
     (`if x ≤ y then … else …`, `if x == y`), `decide` on closed propositions and on
     `x ≤ y`-shaped goals, `Bool.and_eq_true`-style rewriting, `cases b <;> simp`, and the
     interplay of Prop statements (`(<= a b)` in a statement) with Bool code.
   - This suite targets the surface-encoding gap (ansatz compiles `if` to `Bool.rec` and
     comparisons to `Nat.ble`/`Nat.beq`), so cover both encodings' sides.

For both: write the Lean file, check it with the Lean toolchain (every theorem must be accepted
by Lean, with its proof), then write the ansatz test with the line-by-line translation (the
translation rules are in `list_conformance_test.clj`'s docstring and the README "Tactics"
section). Run it in your REPL.

## Scope fence
New files only: `test/lean/{records,bool_decide}_conformance.lean` and
`test/ansatz/{records,bool_decide}_conformance_test.clj`. Do not change `src/`. A theorem that
fails goes into `known-gaps` with a one-line diagnosis of the CAUSE: which tactic, which missing
feature or bug, and whether it is a translation problem. Do not weaken the statement or rewrite
the proof into a non-Lean shape to make it pass. The tests must be green with the known-gaps maps.

## Acceptance
Both suites green in your REPL. The result reports both scores, plus a table of the known gaps
grouped by cause, which is the key output.
