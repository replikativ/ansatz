# Contract lane migration

There is one product interpreter: the SDK's canonical Java engine. `bin/run-test-contracts` continues its broad Java contract suite, not an alternative interpreter product configuration. Its Clojure fixtures and legacy readers are test support; `TypedLongMemo` remains a shared compact kernel-projection utility, not another runtime. The optional SDK JAR/consumer gate remains `bin/run-lean-jvm-checks`.

| Requirement | Mandatory canonical coverage | Legacy material retained only in the optional research lane |
| --- | --- | --- |
| Bounded, malformed serialized input | SDK artifact JSON/ZIP/path/digest/cohort models; Java `graph-checks.clj` and `module-data-graph-checks.clj` reject malformed imports before publication | The 37 exact World checkpoint/restore tests describe a retired public wire target, not the current artifact API |
| Alias, cycle and DAG ownership | Java graph/fork/import-sharing checks and selected-owner/module profiles; SDK managed-construction and argument/value tests | World graph serialization remains a comparison oracle |
| Source/code identity and readiness | Java header, generation, code-demand, initialization and initializer-publication checks; SDK publisher/startup and source/artifact admission models | Earlier native-project compiler models validate their frozen implementation, not the current canonical compiler |
| Paused/result ownership and continuation readiness | Java continuation, release-transaction, HostGuest and code-demand checks | The old World continuation shape is not asserted to be the Java frame representation |
| Fork isolation and inherited code | Java fork, graph, code-demand and generation checks, including copied roots and pending boundaries | Provider-first facade contexts and World checkpoints retain separate semantics; there is no public SDK fork claim |
| RAW constructor/kernel bridge behavior | The Java runner explicitly loads `kernel_cases_on_raw_test.clj` and kernel bridge/projection tests | The broader old World RAW/preseal script remains optional |
| Compiled execution optimization | Ordinary canonical engine and public API behavior remain mandatory; no speculative JIT claim | Pattern typed-tail, sparse/prepared compiler and old coherent-consumer packaging are not product release gates |

`bin/run-lean-hosting-research-checks` explicitly retains the unpublished facade source audit, World checkpoint/restore suite, old compact cold-controller/native-store tests, old native-project metadata models, broader RAW/preseal checks, coherent-consumer infrastructure and optional Pattern preparation. None opens a public SDK feature merely by passing.

The canonical native source service's cold/cache/edit/reload/export/load tests require an explicit toolchain and producer bundle and remain their documented separate acceptance gate. The old native-project metadata runner does not substitute for that current implementation.

No JVM/native run is claimed by this source relocation. The root operator must rerun the canonical contract lane and SDK gates on the final integrated source cohort. The generic relocation verifier checks current files and preserved historical Git bytes separately; it never relabels a new runtime as an old accepted capture.
